# SEO-аналитика сайта evakuator.uz

Дата аудита: 3 сентября 2026

Материал для внутреннего использования SEO-специалистом при старте настройки SEO. Содержит только данные по сайту evakuator.uz — без информации об агентстве-исполнителе аудита, наград, кейсов и коммерческих условий.

## 1. Ключевые выводы стратегии

1. Базовое условие роста — переход от текущей структуры к полноценной многостраничной структуре сайта.
2. Google — основная поисковая система в Узбекистане, поэтому её алгоритмы приоритетны для видимости. Ключевые факторы:
   - **EEAT** (Experience, Expertise, Authoritativeness, Trustworthiness).
   - Внешняя оптимизация: Google оценивает не только текст на странице, но и то, подтверждается ли экспертиза за пределами сайта — отзывами на независимых площадках, упоминаниями в каталогах и медиа, реальными доказательствами работы.
3. Классическая оптимизация под Google и Яндекс напрямую влияет на видимость в AI-ответах (GEO) — это стоит учитывать при планировании контента.

## 2. Охват семантического ядра

По результатам тестового сбора семантического ядра на русском и узбекском языках:

| Язык | Топ-10 Google | Топ-3 Google |
|---|---|---|
| Русский | 47% запросов | 26 формулировок |
| Узбекский | 32% запросов | 8 формулировок |

**Причина отставания узбекской версии:** узбекская версия сайта переключается без смены URL (нет отдельного адреса для языковой версии), что мешает индексации и ранжированию.

**Рекомендация для специалиста:** в приоритете — настройка отдельных URL для языковых версий (`/ru/` и `/uz/`) с корректными атрибутами `hreflang`.

## 3. Аудит сайта: оценка по направлениям

Оценка по шкале до 10 баллов — чем ниже балл, тем выше приоритет работ по направлению.

| Направление | Оценка |
|---|---|
| Техническая оптимизация | 4 |
| Внутренняя оптимизация | 2 |
| EEAT и коммерческие факторы | 4 |
| Хостовые факторы | 7 |
| Внешняя оптимизация | 1 |
| Трафик и поведенческие факторы | 2 |

Наиболее проблемные зоны: **внешняя оптимизация** (1 балл), **внутренняя оптимизация** и **трафик/поведенческие факторы** (по 2 балла) — с них стоит начинать работу.

## 4. План работ по месяцам

### 1-й месяц

- Технический аудит сайта и подготовка рекомендаций для разработчиков (настройка серверных редиректов, решение вопроса постороннего контента на служебных поддоменах и т.д.).
- Настройка отдельных URL для языковых версий (`/ru/` и `/uz/`) с корректными атрибутами `hreflang`.
- Добавление микроразметки.
- Сбор семантического ядра и подготовка структуры для приоритетных разделов.
- Формирование контент-плана для on-page оптимизации (с учётом приоритетности).
- Подготовка ТЗ на минимально достаточный контент для новых страниц.
- Аудит присутствия компании на картах и в бесплатных справочниках и каталогах.
- Формирование дашборда с выводом основных показателей сайта и KPI.

### 2-й месяц

- Расширение структуры сайта: запуск приоритетных разделов.
- On-page оптимизация страниц в соответствии с контент-планом (включая расширение семантического ядра, оптимизацию мета-тегов и текстов).
- Аудит страниц услуг по коммерческим, поведенческим факторам и YMYL, формирование рекомендаций по доработке содержания страниц.
- Подготовка рекомендаций по внутренней перелинковке сайта.
- Аудит ссылочной массы сайта и конкурентов, формирование стратегии внешней оптимизации с учётом выявленного ссылочного спама.
- Ежемесячная отчётность.

### 3–6-й месяц

- Проведение ежемесячного аудита. Контроль основных SEO-параметров: количество ссылок, количество страниц в индексе Google и Яндекс, качество индексации и т.д.
- Мониторинг позиций сайта и точечная доработка страниц под соответствующие запросы.
- On-page оптимизация страниц в соответствии с контент-планом (включая расширение семантического ядра, оптимизацию мета-тегов и текстов).
- Расширение семантического ядра и поиск кластеров для масштабирования контента.
- Развитие информационного раздела.
- Доработка сайта по коммерческим, поведенческим факторам, YMYL и EEAT-факторам, формирование рекомендаций по доработке содержания страниц.
- Реализация стратегии по внешней оптимизации сайта.
- Ежемесячная отчётность.

## 5. Что нужно для старта работы специалисту

- Доступ к Google Search Console и Яндекс.Вебмастер для сайта evakuator.uz.
- Доступ к системе аналитики (Google Analytics / Яндекс.Метрика).
- Доступ к CMS/хостингу сайта для внесения технических правок (редиректы, hreflang, микроразметка).
- Текущий список семантического ядра (ru/uz) как отправная точка для расширения.
- Список приоритетных разделов сайта, которые нужно добавить при переходе к многостраничной структуре.
